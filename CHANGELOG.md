# Changelog

All notable changes to Line3D are documented here.

## [0.1.2] - 2026-10-9

### Changed
- Fixed a bug related to line not being updated when assigned through parent node's curve.
- Fixed a bug with curves that have less than 2 points.

## [0.1.1] - 2026-10-8

### Added
- Linux and macOS builds.
- Automated multi-platform release packaging through GitHub Actions.

### Changed
- Release downloads now include compiled libraries for supported platforms.

## [0.1.0] - 2026-10-6

### Added
- Initial release of Line3D with Windows support.
